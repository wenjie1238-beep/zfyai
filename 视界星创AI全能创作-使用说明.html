视界星创 AI 全能创作本地短剧创作工作台
PRODUCT GUIDE / 使用说明

从一句话，走到一部短剧。

这是一套以本地 GPU 与 ComfyUI 工作流为核心的 AI 短剧创作工具。按照创作航线逐步推进，让人物、场景、镜头和成片在同一个项目里连续完成。

一、快速开始

  1. 解压产品目录后，使用目录内的专用启动器启动。
  2. 首次启动按提示完成本地环境配置，等待工作台和本地引擎加载完成。
  3. 主页点击“创建创作任务”，填写项目名称，选择横屏或竖屏、画风和分辨率。
  4. 点击“创建”进入工作台，按左侧创作航线逐步生成。
软件以本地 GPU 与 ComfyUI 为核心，云端能力暂未开放。实际功能以当前安装包版本为准。

二、创作航线怎么用

创作设定

确定画幅、题材、基调、画风和基础输出参数。

故事蓝图

整理人物清单、场景清单、人物关系和幕次结构。

剧情编排

把故事拆成可执行的剧情段落，为后续生成做准备。

提示词总览

统一查看和整理人物、场景、镜头与视频提示词。

人物设计 / 场景设计

分别生成角色三视图与场景视觉资产，保持后续镜头的视觉统一。

镜头成片

按分段或镜头排队生成视频，查看状态、预览结果，必要时重做或上传到无限画布。

成片交付

集中整理完成的素材，导出项目资产与最终成果。

三、常用功能

  • 左右侧栏可以折叠，收起后扩大中间工作区。
  • 无限画布用于整理人物、场景、视频和自定义资产。
  • 引擎中心用于查看本地 ComfyUI 状态、队列和执行情况。
  • 生成前建议关闭其他占用显存的程序；停止任务后等待状态刷新完成，再开始新任务。
  • 当前对外统一描述为十多种视觉画风，包含写实、电影、动漫、3D、手绘、水彩、油画、水墨、平面插画、赛博朋克和国风幻想等方向。

四、运行建议与故障排查

  • 建议使用支持 CUDA 的 NVIDIA GPU，并保持显卡驱动稳定。
  • 软件按最低 12GB 显存的本地运行目标设计，实际速度受显卡、内存、分辨率和工作流复杂度影响。
  • 生成失败时，先查看工作台状态、引擎中心和日志，确认模型与工作流文件完整，不要连续重复点击生成。
  • 生成速度较慢时，关闭其他 GPU 程序，等待模型首次加载完成，减少同时排队任务。
  • 如预览卡片显示不完整，可展开或折叠侧栏、调整窗口大小后重新打开预览。
遇到问题时，请保留项目名称、操作步骤、错误提示和相关日志，再联系产品页面展示的官方联系方式。不要直接删除核心运行文件。
